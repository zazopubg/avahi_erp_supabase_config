# assets/

هذا المجلد يحتوي على الهيكل الكامل للأصول (assets) المطلوبة في **Prompt
00**. ملفات الصور (`.png`) والخطوط (`.ttf`) هي حالياً ملفات **نائبة
(placeholder) فارغة** بأسمائها النهائية الصحيحة ومسجّلة في `pubspec.yaml`،
بحيث يعمل `flutter pub get` و `flutter run -d chrome` دون أخطاء مسارات.

ملفات SVG (`icons/svg/`) وLottie (`animations/`) تحتوي على بنية دنيا
**صالحة الصياغة (valid syntax)** كي لا تُسبب استثناءات وقت التشغيل عند
تحميلها عبر `flutter_svg` أو `lottie`، وسيتم استبدال محتواها بالتصميم
النهائي في خطوات لاحقة (واجهات المستخدم — Prompt 01 وما بعده).

| المجلد              | الحالة                                   |
|---------------------|--------------------------------------------|
| `images/`           | ملفات PNG نائبة فارغة — بانتظار التصميم النهائي |
| `icons/svg/`        | SVG صالح الصياغة (شكل فارغ) — بانتظار الأيقونات النهائية |
| `fonts/`            | ملفات TTF نائبة فارغة — **يجب استبدالها بخطوط Cairo / IBM Plex Sans Arabic الفعلية قبل الإطلاق** |
| `animations/`       | JSON بنية Lottie دنيا صالحة — بانتظار الرسوم النهائية |
| `l10n/`             | ✅ مكتمل فعلياً (app_ar.arb / app_en.arb) بالمفاتيح الأساسية |

> ⚠️ ملفات الخطوط الفارغة **لن تُعرض بشكل صحيح** في المتصفح حتى يتم
> استبدالها بملفات .ttf حقيقية. هذا متوقع في هذه المرحلة (Prompt 00) لأن
> الهدف هو تجهيز الهيكل والتسجيل في pubspec.yaml فقط.
